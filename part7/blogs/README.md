# Blogs

Small full-stack blog app with a Node/Express backend and a React frontend.

## Structure

- `backend/` API, models, scripts, and backend tests
- `frontend/` UI, page views, reusable components, and frontend tests

## Common Commands

- `npm run dev` to run backend and frontend together
- `npm run test` to run backend tests and frontend unit tests
- `npm run build` to build the frontend
